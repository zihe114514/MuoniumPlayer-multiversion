# MuoniumPlayer

**把音乐装进 Minecraft。**

一个 Minecraft 音乐客户端 Mod:手机音乐 App 般的播放器、逐字歌词、灵动岛、一起听房间、无缝切歌 —— 全部画在游戏里,不弹浏览器、不切窗口。纯客户端,普通服务器**不用装任何东西**。

## 8 个聚合音源,一个播放器

网易云音乐、QQ 音乐、酷狗、YouTube Music、哔哩哔哩、汽水音乐、Spotify、GD 音乐台 —— 支持扫码登录、多账号切换,歌单、VIP 音质、每日推荐、私人 FM 都在游戏里。

- **LX 脚本音源**:兼容 lx-music 社区脚本,更多渠道自己加
- **灰色歌曲自动解灰**:无版权的曲目跨平台匹配替身流,毫秒级亮起无感起播,歌单不再灰一半;不满意就右键手动换源
- **全渠道导入歌单**:粘贴链接自动识别平台

## 逐字歌词

TTML / QRC / KRC / YRC / LRC 全格式,逐字上浮填涂、真高斯发光。

- **十种全屏排版样式**,每种带独立参数
- **3D 世界歌词**:歌词逐字画进游戏世界,多种动效模式
- 支持译文与罗马音,歌词来源可手动指定
- **中键钉词**:列表里中键一点,四源候选逐字预览后固化

## 灵动岛

切歌、音量、下载进度、报错,全从顶部胶囊显示。8 种形态、四级优先级调度,播放器收起时动画合入岛。游戏内 **Ctrl+F** 从岛上长出快捷搜索栏,不切出游戏就能找歌。

## Automix 无缝切歌

前一首还没结束,下一首已经铺进来了。节拍与人声分轨双模型挑接缝,低频交换、人声让路、节奏锁定、音高匹配;进阶模式整曲扫描打分选接缝点,低配设备自动回退纯数学引擎。手机上同样能跑。

## 一起听

和朋友听同一首歌,共三种开法,**后两种无需任何服务端**:

- **服务器房间**:服主装 mpsync 即可全服开房
- **直连房间**:房主客户端就是引擎,复制一条邀请串发给好友,粘贴即进;房主退出第三方服务器,房间照常进行
- **局域网房间**:零配置,主机开房成员自动发现加入

房间里还有:

- **民主点歌**:点歌排队、投票切歌(过半)、投票踢人(80%)
- **会员借流**:成员用自己账号的会员权限解析,Cookie 永不出本机,全房收听
- 房内同样支持 Automix 无缝过渡

## 播放体验

- **音效**:ViPER 蝰蛇音效 + 混响,游戏内调参面板
- **频谱**:实时音乐频谱接入 HUD 与全屏播放器
- **系统联动**:键盘多媒体键、耳机线控都能控制游戏内播放,外部播放器和游戏互相跟随
- **全屏原生中文输入**:内置输入法引擎,游戏内直接敲拼音搜歌
- **液态玻璃 UI**:真边缘折射毛玻璃,15 套主题预设、字体自由替换、封面取色
- **桌面歌词**:游戏外也能挂着看词
- 播放时自动压掉原版游戏音乐:只让路「音乐」,不碰音效与环境音

## 安装:三步装好

1. **选好版本与加载器** —— 不确定就去看启动器里整合包的详情
2. **装前置** —— Fabric 侧:Fabric API + Fabric Language Kotlin;Forge / NeoForge 侧:Kotlin for Forge
3. **丢进 mods,开听** —— jar 放进 `.minecraft/mods/`,进游戏按 **右 Shift** 打开播放器

Windows 开箱即用;Linux 与安卓首次启动自动补齐组件,按提示重启即可。

### 手机上游玩

推荐 FCL、Zalith Launcher 等安卓启动器:

- 26.3 用 MobileGL 渲染器(已实测适配);其它版本建议 MobileGlues 并关闭 ANGLE,Zink / VirGL 等 Mesa 渲染器也已适配
- 触屏全手势支持:列表惯性甩动、队列长按拖动排序
- Automix 在安卓上纯本地推理,不需要装任何额外环境

## 常见问题

**装上后界面一个像素都没有?**
屏幕上会有一块原版字体的提示,告诉你缺什么、下一步做什么,照着走即可;手机端先检查渲染器选择(见上)。

**歌词匹配错了 / 想换歌词来源?**
播放器里可以手动指定歌词来源,译文、罗马音都支持。

**服务器玩家怎么一起听?**
服主装 mpsync 开服务器房间;不想动服务器就用直连或局域网房间,完全不需要服务端。
