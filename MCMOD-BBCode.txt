[h1=概述]
MuoniumPlayer（μPlayer，Mod ID: muonium）是一个专为 Minecraft 打造的客户端音乐播放器 Mod，把一个功能完整的音乐播放器直接画进游戏里，不弹浏览器、不切窗口。

Mod 支持网易云、QQ 音乐、酷狗、汽水音乐、Apple Music、YouTube、B 站、Spotify 等多平台曲库，具备毫秒级逐字歌词、光影兼容的 3D 世界歌词、手机级蝰蛇音效与环境回声、无缝混音切歌与多人一起听。
纯客户端 Mod，单人游玩或进入任何普通原版、插件或第三方模组服务器时均可独立使用全部核心播放功能，服务端无需安装任何插件。

[h2=版本与运行环境]
- 1.20.1：Fabric / Forge，Java 17
- 1.21.1：Fabric / NeoForge，Java 21
- 1.21.11：Fabric / NeoForge，Java 21
- 26.2：Fabric / NeoForge，Java 25
- 26.3：Fabric / NeoForge，Java 25

全平台支持 Windows、Linux、macOS 以及安卓手机端（FCL、Zalith Launcher 等移动端启动器）。发布包内置 Windows 运行库，Linux 与安卓首次进游戏会自动补齐所需组件。
安装前置：Fabric 需安装 Fabric API 与 Fabric Language Kotlin；Forge / NeoForge 需安装 Kotlin for Forge。
注意：安装包命名格式为 MuoniumPlayer-<MC版本>-<加载器>-<版本号>.jar。其中 1.21.1 与 1.21.11 仅差一个字符且不通用，安装时请仔细核对文件名。

[h1=首次启动与快捷键]

[h2=首次启动向导]
首次加载模组进入游戏会自动弹出全屏设置向导：
欢迎（彩虹描字动画） → 账号登录 → 音源偏好 → 视觉外观 → Automix 切歌模型选择 → 配置完成。
玩家可在向导中直接选择默认音源、扫码登录平台账号、微调毛玻璃主题，并根据设备性能选择是否安装 Automix 混音模型（均可选；跳过时仍可正常使用原版轻量智能淡化，后续可在设置界面中随时安装修改）。向导完成后仍可在游戏内随时调整各项设置。

[h2=按键映射与控制方式]
可在游戏内"选项 → 控制 → 按键绑定"中自由调整：
- 打开 / 关闭播放器大厅：右 Shift（Right Shift）
- 灵动岛快捷搜索找歌：Ctrl + F（无需打开大厅界面，直接从顶部弹出搜索栏）
- 呼出 / 编辑 HUD 布局：H
- 上一曲 / 下一曲：Page Up / Page Down
- 音量增大 / 减小：小键盘 + / -
- 暂停 / 继续播放：小键盘 *
- 硬件联动：支持键盘自带的多媒体播放键、切歌键与耳机线控；在游戏外使用系统其他播放器放歌时，模组 HUD 亦能动态感知并联动呈现正在播放的歌曲。

[h1=混音调度与自动化]

[h2=Automix 无缝切歌]
在前后两首歌曲切换期间提前准备并实现两曲无缝卡点过渡，消除切歌空白停顿：
- 播放器自动分析两首歌的节奏与鼓点位置，在最合适的一拍平滑切入，实现类似 DJ 现场打碟的连续听感。
- 原版智能淡化引擎：采用等功率交叉淡化算法，支持调节重叠时长、跳过前奏、小节节奏对齐、低频交换（Bass Swap）、去人声平滑淡入、节奏锁定与音高跳跃规避等参数。
- Folia Automix 引擎：基于 AI 模型的智能混音调度，支持 Beat This!（BPM 节拍与拍点探测）与 HTDemucs（音轨分轨人声分离）模型，支持 beatCut、bassSwap、tailRide、plainBlend 四种过渡家族动画，分析失败自动无缝平稳降级至经典淡化。
- 全平台自适应：低配电脑自动启用低开销算法，安卓启动器端支持纯本地轻量推理，不卡游戏。

[h2=环境自适应选曲（Ambient DJ）]
模组实时监控玩家在游戏中的处境与活动状态（共 14 种环境状态：水下深潜、地下矿洞、夜间生存、激烈战斗、高空建筑、平原农作、荒野探索等）：
- 当玩家行为在某一状态持续满足稳定期后，自动提炼环境情绪关键词在曲库中挑选契合氛围的曲目切入，挖矿有挖矿的调，探洞有探洞的味。
- 具有防抖机制与冷却保护，杜绝在环境交界处频繁误切歌；切歌前灵动岛提前发出意图提示，支持快捷键手动触发。

[h1=多人联机：一起听系统（Listen Together）]

[h2=三种开房拓扑架构]
- 直连房间（P2P）：
  - 房主点击开房即可生成专属加密邀请串，好友在播放器内粘贴即可秒进；
  - 核心逻辑在房主客户端独立运行，完全不依赖第三方服务器，房主即使退出所在服务器，房间依然平稳存续，永不掉线。
- 局域网房间：
  - 处于同一局域网（LAN）或 WiFi 内的玩家自动通过组播发现，无需复杂配置，单机局域网开黑首选。
- 服务器一起听房间：
  - 需服务端安装官方配套组件 mpsync（覆盖 1.20.1 ~ 26.3 的 Fabric / Forge / NeoForge / Paper 服务端）；
  - 全服共享统一电台，与 Melodify（modernMP）客户端完全互通，底层协议完全开放。
- 网易云官方一起听：
  - 绑定网易云账号即可通过官方链接、邀请码或"房间号#邀请人ID"无缝接入网易云官方同步房间。

[h2=房间协同交互机制]
- 会员借流机制：房内任意一位成员拥有 VIP/SVIP 权限时，可开启"贡献解析"为全房间队友代取音频。仅在本地生成带时效签名的临时播放直链分发，Cookie 与账号私钥绝不上报或脱离本机。
- 民主点歌台：支持房内成员排队添加公用点歌单；投票切歌需超过 50% 成员赞成；投票移出扰乱成员需达到 80% 赞成率。
- 房内统一 Automix 混音：全房同步接收同一套无缝切歌时间戳，确保低配与高配队友听到同一段丝滑过渡。

  - 支持拖拽滑条自由调节在屏幕上的上下挂载位置；
  - 常驻模式下可集成显示游戏帧率（FPS）、网络延迟（Ping）、现实时间与正在播放曲目。
- OneConfig 框架集成：在 Fabric 1.21.1 / 1.21.11 / 26.2 环境下，模组原生支持与 OneConfig v1 设置集成，未安装时平滑回退至内置设置页。

[h1=音频解码、缓存与安全]

[h2=解码与缓存策略]
- 解码格式：支持 MP3、AAC、M4A、FLAC、OGG、WAV 等全流媒体容器格式；播放条实时显示"所选档位 → 实际取得档位"。
- 原版游戏音乐智能压制：模组出声时自动淡化 Minecraft 原版游戏 BGM，生物、脚步、方块交互音效不受任何削弱。
- 本地音频缓存管理：已播放歌曲在本地自动缓存，存储上限支持自由设置（不限制 / 2 / 4 / 8 / 16 / 32 / 64 GB）；达到上限时自动清理最久未播放音频，支持在设置页一键手动清理。
- 毫秒级播放状态记忆：重开游戏后，当前歌曲精确播放毫秒数、播放模式、音量以及临时播放队列全量自动恢复。

[h2=可选增强组件：FFmpeg]
FFmpeg 属于可选外置组件，主要用于辅助动态封面渲染、特殊容器封装与 B 站特殊高规格音频流解析。
- 安装方式：解压至操作系统 PATH 环境变量中，或直接放置在 .minecraft/config/muonium/bin/ 目录下即可。
- 未安装状态下完全不影响基础在线音乐播放、电台收听与静态封面展示。

[h2=移动端（Android）启动器深度适配]
针对在手机端使用 FCL（Fold Craft Launcher）或 Zalith Launcher 启动器游玩的用户：
- 触屏手势：全面支持曲库列表惯性甩动滑动、播放队列长按拖拽重排等原生手势。
- 渲染器选型建议：
  - 26.3 版本：强烈推荐选用 MobileGL 渲染器；
  - 1.20.1 ~ 1.21.x 版本：推荐使用 MobileGlues 渲染器并建议关闭 ANGLE 转换；同时完美兼容 Zink、VirGL 等 Mesa 驱动。
- 本地混音推理：Automix 混音在移动端支持纯本地轻量推理，无需额外安装繁琐环境。

[h2=配置文件与数据隐私说明]
- 文件存储位置：
  - 核心配置文件：.minecraft/config/muonium/
  - 自定义外部字体：.minecraft/config/muonium/fonts/
  - 自定义音源脚本：.minecraft/config/muonium/scripts/
  - 本地缓存与二进制：.minecraft/config/muonium/cache/ 与 bin/
- 数据隐私安全性：
  - 账号凭据仅存放于玩家本地设备，绝不经过第三方服务器中转；
  - 一起听借流仅在本地生成带签名的时效链接，绝不上报账号 Cookie；
  - 版本更新检查每 30 分钟拉取一次发布清单，仅在主菜单低频提示，客户端绝不会自动下载或擅自替换 jar 文件。
