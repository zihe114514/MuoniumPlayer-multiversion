# Skija 设置中心人工验收交接

核对日期：2026-11-24。用户要求本轮尽快收尾，游戏验收由人工完成。

本目录是独立的迁移和验收工程。已接入主项目的设置模型、预设、字体、HUD、输入及既有 Skija 帧；安装验收包后通过原 H 打开路径进入。当前不将它写入主项目正式源码根，待人工确认后再融合。编译、模型测试和离屏绘制均不代表全部页面已达到 1:1。

## 人工使用

推荐先验收 26.3，随后分别验证其他精确版本和加载器。

- 正式实例使用 dist/MuoniumConfig-Skija-<MC>-<loader>-0.1.0.jar，并同装对应 MuoniumPlayer。
- 主项目开发运行使用 build/devdist/ 下匹配的 -dev.jar。旧 Fabric/Forge 的开发命名包不得用于正式实例。
- 便捷同步：在本目录执行 .\tools\sync-acceptance.ps1 -Version '26.3' -Loader 'fabric'。随后在对应主项目版本树按既有方式运行客户端。
- 沿用主项目的 H 打开绑定及自定义按键；对照原 UI 时用 JVM 参数 -Dmuonium.config.skija.disabled=true 重启。
- 核对启动日志中的 [MuoniumConfig/Skija] session ready 和测试包指纹，避免验收到旧包。不要在同一实例安装两个版本的 Skija 验收包。

本轮没有启动游戏，也没有改变各 run/mods 的安装状态。构建和验证记录在本工程 build/closeout-*；产物和日志不进入 Git。

## 已接线范围

设置页及原常用树、28 种控件、文本编辑和历史事务；主题及界面偏好；模组、Profile、模板、键位和 Credits；全局搜索；HUD 编辑器、库、锚定、合并及运行期；通知中心与 toast；原声音、字体和真实头像。各页面的来源、交互和已知差异分别记录在其他 parity 文档。

## 已知实现差异

以下是代码差异，不只是不齐全的人工截图证据；验收人应知情：

- 设置标题的 Medium 500 字重、实际行高和 nested tooltip 12sp 尚未完全收口，详见 settings-parity.md。
- 设置页局部搜索使用同步筛选；全局搜索已接异步 provider。扩展控件的特殊 metadata、具体 List subtype 及文件选择仍取决于宿主能力。
- HUD 字体下拉箭头的动画中间帧尚未旋转原 SVG。
- HUD 剪贴板保存深复制快照，原实现的活引用语义有差异。
- 输入法预编辑、复杂脚本和双向排版尚无完整的原生语义验收。
- 原版本未定义或无法确认的旧 HUD/schema 不会伪造等价适配；查看迁移诊断和 migration-parity.md。

最终 implementation 阶段审计 blockingChecks=0，5 项已登记的中立搜索实现证据通过；保留 569 项人工/逐项证据 pending。这不是 569 项功能失败，也不是 569 项已通过 1:1。完整功能映射保留人工 pending。该计数表示待补充的逐项证据，不能解释为所有功能都失败，也不能改成已经达到 1:1。

## 人工验收顺序

1. 启动、H 打开/关闭、连续重开、返回/前进、失焦、ESC、按键记录与 IME。
2. 每页与原版本对照布局、字体、颜色、hover、弹窗、滚动、过渡和声音；检查不同窗口尺寸、GUI scale 和四个主题。
3. 修改/重置/撤销设置；重进游戏确认持久化；逐个切换命名 Profile，检查旧音乐与新增 HUD 不串档。
4. HUD 拖拽、缩放、锚点、合并、复制、撤销、库预览；关闭 UI 后继续显示，改变 GUI scale 后核对物理大小。
5. 搜索、通知/侧键点击、真实头像、文件对话框、离线与缺资源；最后检查退出及资源重载。
6. 逐精确版本 × 加载器记录通过与问题；确认后再从独立目录融合共享业务和各版本桥，移除验收专用入口/Mixin。
