# Skija 设置中心迁移工程

继承 ../AGENTS.md。用户明确授权在此独立目录重写附属 MuoniumConfig 的界面；这是验收工作区，尚未融合。

- 原附属仓只读；主项目已有工作区修改必须保留。
- src/main 的业务调用只接主项目公开的模型/compat/预设契约。共享 Java 17；不引 Compose、Skiko、Kotlin 或第二份 Skija/native。
- host 接宿主，ui/model 不直接引用 MC/loader；mixin 只负责验收包 H 路由。融合时删除验收 mixin/元数据并从主入口直接打开。
- 不把已编译写成游戏实测，不把第一版写成 1:1 已完成。功能表中每项分别记录实现、自动测试、游戏验收。
- 每一项新宿主接口先查真实声明；七车道分别编译，不能凭相同名称复制适配。
- 构建输出只写本目录 build/、dist/；不改主项目发布包、版本号或线上配置。提交、推送和发布沿用根规范的用户授权要求；只纳入本任务改动，产物和日志不进入 Git。
